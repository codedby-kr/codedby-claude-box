---
argument-hint: '[compact 시 보존할 맥락 힌트]'
---
현재 대화의 맥락을 분석해서 `/compact` 뒤에 붙일 보존 메시지를 생성해줘.

## 생성 절차

1. 현재 대화를 분석하여 아래 항목들을 추출 (있는 것만, 없으면 해당 섹션 생략)
2. `/compact` + 생성된 메시지를 사용자에게 보여줘 (직접 실행하지 말고 보여주기만)
3. 사용자가 수정하거나 그대로 쓸 수 있게

## 추출 항목 (있는 것만 포함)

### 대전제
- 이 세션의 큰 목적/주제 (한 줄)

### 전체 진행 목록
- 해야 할 일 전체 목록 (번호 매기기)
- 각 항목 상태: 완료/진행중/미착수

### 완료된 작업
- 이미 끝난 작업들의 핵심 결과 (결정사항, 변경한 파일 등)

### 현재 진행 중
- 지금 하고 있던 작업
- 마지막 사용자 질문/지시 (아직 답변 안 한 것 포함)

### 핵심 결정사항
- 이 세션에서 합의된 중요한 결정 (번복하면 안 되는 것들)

### 참조 파일/경로
- 작업에 필요한 파일 경로들

### 세션 메모리 키워드
- `session-memory-notify.mjs` 훅이 존재하면 compact 후 자동 주입되므로 생략
- 훅이 없으면 `~/.claude-box/data/session-memory/{session-id}/`에서 키워드 목록을 확인하여 포함

## 출력 형식

```
/compact 이 세션은 [대전제 한 줄].

## 완료된 작업
- [항목]

## 현재 진행 중
- [항목]
- 마지막 질문: [내용]

## 핵심 결정사항
- [항목]

## 참조 파일
- [경로]

## 세션 메모리 키워드
- [키워드 목록]
```

## 주의사항
- compact 메시지 자체가 너무 길면 의미 없음 — **각 항목 1~2줄로 압축**
- 코드 스니펫은 넣지 말 것 (파일 경로로 대체)
- 파일 내용을 복사하지 말 것 (경로만 참조)
